# Problem Statement

## Problem Statement

Many beginners looking to practice basic arithmetic (addition, subtraction,
multiplication, and division) don't have a quick, distraction-free way to
test themselves without opening a browser, an app, or a full quiz platform.
This project solves that by providing a lightweight, terminal-based quiz
that lets a user practice one arithmetic topic at a time and immediately
see how they performed.

## Scope of the Project

The project is a single-session command-line quiz application. Scope
includes:

- Collecting the user's name for a personalized experience
- Letting the user choose one of four arithmetic topics
- Presenting 5 multiple-choice questions for the chosen topic
- Giving instant right/wrong feedback per question
- Calculating and displaying a final score out of 5

Out of scope (for this version): multiple topics in a single run, a graphical
interface, persistent score history/storage, difficulty levels, and a timer.
These are listed as possible future enhancements in the project report.

## Target Users

- Students (school/early college level) wanting quick arithmetic practice
- Anyone who wants a simple, no-setup way to test basic math skills
- Beginner programmers/evaluators reviewing this as an introductory
  Python console-application project

## High-Level Features

- Name-based personalized greeting
- Topic menu: Addition, Subtraction, Multiplication, Division
- 5 multiple-choice questions per topic (options a/b/c/d)
- Per-question correctness feedback
- Final score summary out of 5
